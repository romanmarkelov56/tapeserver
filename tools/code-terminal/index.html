Пути должны совпадать с тем, что ждёт клиент Tape. Меняешь здесь — меняется и серверный код на вкладке «Сервер».

  1. npm i express в пустой папке на VPS с Node 20+
  2. Сохранить код ниже как tape-server.js
  3. SC_CLIENT_ID=... node tape-server.js (client_id не обязателен — сервер умеет доставать его сам)
  4. В Tape указать базовый URL http://IP:8080 и сверить маршруты
  5. Проверить: curl http://IP:8080/health → {"ok":true}
